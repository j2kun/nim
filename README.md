# Nim Worksheet

A two-page printable worksheet of Nim variants for 6-year-olds.

## Compile

```sh
pdflatex nim_worksheet.tex
```

This writes `nim_worksheet.pdf`. It requires a LaTeX distribution (such as TeX
Live) with the `extsizes`, `geometry`, `tikz`, `fontawesome5`, `comicneue`, and
`enumitem` packages.
